# ระบบบันทึกสถิติการมาเรียน

ระบบบันทึกสถิติการมาเรียน เป็นเว็บแอปพลิเคชันสำหรับจัดเก็บ ตรวจสอบ และสรุปข้อมูลการมาเรียนของนักเรียนในแต่ละวัน พัฒนาด้วย Google Apps Script และใช้ Google Sheets เป็นฐานข้อมูลกลาง ช่วยลดขั้นตอนการบันทึกข้อมูลแบบเดิม ทำให้ครูสามารถกรอกข้อมูลได้อย่างสะดวก รวดเร็ว และตรวจสอบย้อนหลังได้อย่างเป็นระบบ

ระบบออกแบบให้รองรับการใช้งานผ่านคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ มีหน้าตาทันสมัย ใช้งานง่าย และสามารถปรับข้อมูลพื้นฐานให้เหมาะสมกับบริบทของแต่ละสถานศึกษาได้

## วัตถุประสงค์

* เพื่ออำนวยความสะดวกในการบันทึกสถิติการมาเรียนประจำวัน
* เพื่อช่วยตรวจสอบชั้นเรียนที่บันทึกแล้วและยังไม่ได้บันทึก
* เพื่อจัดเก็บข้อมูลอย่างเป็นระบบและสามารถค้นหาย้อนหลังได้
* เพื่อสรุปจำนวนมาเรียน ขาดเรียน และร้อยละการมาเรียน
* เพื่อสนับสนุนการจัดทำรายงานสำหรับครู ผู้บริหาร และงานสารบรรณ
* เพื่อลดความซ้ำซ้อนและความผิดพลาดในการรวบรวมข้อมูล

## ความสามารถของระบบ

### 1. บันทึกสถิติการมาเรียน

* เลือกวันที่และระดับชั้นที่ต้องการบันทึก
* แสดงจำนวนนักเรียนชายและหญิงทั้งหมด
* บันทึกจำนวนนักเรียนชายและหญิงที่มาเรียน
* คำนวณจำนวนขาดเรียนให้อัตโนมัติ
* มีปุ่ม “มาเรียนครบ” สำหรับกรอกข้อมูลอย่างรวดเร็ว
* ป้องกันข้อมูลซ้ำด้วยการอัปเดตข้อมูลเดิมของวันที่และชั้นเรียนเดียวกัน

### 2. ตรวจสอบการบันทึก

* ตรวจสอบชั้นเรียนที่บันทึกข้อมูลแล้ว
* ตรวจสอบชั้นเรียนที่ยังไม่ได้บันทึก
* ตรวจสอบข้อมูลตามเดือนหรือภาคเรียน
* กรองข้อมูลตามระดับชั้น
* แสดงจำนวนวันที่ต้องบันทึก บันทึกแล้ว และยังไม่บันทึก
* แก้ไขหรือลบประวัติการบันทึกได้

### 3. สรุปและออกรายงาน

* สรุปจำนวนนักเรียนทั้งหมด
* สรุปจำนวนมาเรียนและขาดเรียน
* แยกข้อมูลนักเรียนชายและหญิง
* คำนวณร้อยละการมาเรียน
* แสดงรายละเอียดแยกตามระดับชั้น
* สร้างรายงานสถิติการมาเรียนรายวันเป็นไฟล์ PDF
* จัดเก็บไฟล์รายงานใน Google Drive

### 4. ระบบบันทึกครูเวร

* บันทึกผลการปฏิบัติหน้าที่ครูเวรประจำวัน
* เลือกข้อความบันทึกสำเร็จรูปได้
* เพิ่มรายละเอียดหรือเหตุการณ์สำคัญเพิ่มเติมได้
* บันทึกชื่อครูเวรประจำวัน
* ค้นหาและแสดงประวัติการบันทึก
* แก้ไขและลบข้อมูลได้
* สร้างรายงานครูเวรเป็นไฟล์ PDF จากตารางประวัติ

### 5. ระบบผู้ดูแล

ผู้ดูแลสามารถกำหนดและจัดการข้อมูลสำคัญของระบบ ได้แก่

* ปีการศึกษา
* ชื่อโรงเรียน
* สังกัด
* ชื่อผู้อำนวยการสถานศึกษา
* โลโก้โรงเรียน
* รูปแบบการกรอกจำนวนนักเรียน
* ข้อมูลระดับชั้นและห้องเรียน
* จำนวนนักเรียนชายและหญิง
* ครูประจำชั้น
* ภาคเรียนและช่วงวันเปิด–ปิดภาคเรียน
* วันหยุด
* วันเรียนชดเชย

## ขั้นตอนการทำงาน

1. ผู้ดูแลระบบกำหนดข้อมูลโรงเรียน ชั้นเรียน และภาคเรียน
2. ครูเลือกวันที่และระดับชั้นที่ต้องการบันทึก
3. ระบบดึงจำนวนนักเรียนชายและหญิงของชั้นเรียนนั้น
4. ครูกรอกจำนวนผู้มาเรียนหรือกดปุ่ม “มาเรียนครบ”
5. ระบบคำนวณจำนวนขาดเรียนให้อัตโนมัติ
6. ข้อมูลถูกบันทึกลงใน Google Sheets
7. ผู้เกี่ยวข้องสามารถตรวจสอบ แก้ไข หรือลบข้อมูลย้อนหลัง
8. ระบบนำข้อมูลมาสรุปและสร้างรายงาน PDF

## ฐานข้อมูลที่ใช้

ระบบจัดเก็บข้อมูลใน Google Sheets โดยแบ่งเป็นชีตหลัก ได้แก่

* ผู้ใช้งานระบบ
* ตั้งค่าข้อมูลโรงเรียน
* สถิตินักเรียนทั้งหมด
* บันทึกการมาเรียน
* ตั้งค่าภาคเรียน
* วันหยุด
* วันเรียนชดเชย
* บันทึกครูเวรประจำวัน
* สรุปการมาเรียนรายวัน

## จุดเด่นของระบบ

* ใช้งานง่าย ไม่ซับซ้อน
* ลดภาระการรวบรวมข้อมูลของครู
* ลดความผิดพลาดในการคำนวณ
* ตรวจสอบข้อมูลย้อนหลังได้
* รองรับการเพิ่ม แก้ไข ลบ และค้นหาข้อมูล
* แสดงผลได้เหมาะสมกับทุกขนาดหน้าจอ
* ใช้บริการของ Google ที่โรงเรียนสามารถเข้าถึงได้
* ปรับข้อมูลให้เหมาะกับแต่ละสถานศึกษาได้
* สร้างรายงาน PDF ได้โดยอัตโนมัติ
* ระบบพัฒนาเสร็จสมบูรณ์และพร้อมใช้งาน

## ความปลอดภัยของข้อมูล
เนื่องจากผู้ใช้งานทั่วไปซึ่งเป็นคุณครูอาจประสบปัญหาในการเข้าสู่ระบบ ผู้พัฒนาจึงออกแบบให้หน้าบันทึกข้อมูลทั่วไปสามารถใช้งานได้โดยไม่ต้องมีบัญชีผู้ใช้รายบุคคล เพื่อให้การบันทึกข้อมูลเป็นไปอย่างสะดวกและต่อเนื่อง อย่างไรก็ตาม ระบบกำหนดให้เผยแพร่และใช้งานเฉพาะภายในองค์กรเท่านั้น โดยส่งลิงก์ให้เฉพาะบุคลากรที่เกี่ยวข้อง และแยกหน้าผู้ดูแลระบบซึ่งต้องเข้าสู่ระบบก่อนดำเนินการตั้งค่า แก้ไข หรือลบข้อมูลสำคัญ ทั้งนี้ ควรจำกัดสิทธิ์การเข้าถึง Google Sheets, Google Drive และ Google Apps Script เฉพาะผู้ดูแลระบบ รวมถึงสำรองข้อมูลอย่างสม่ำเสมอ เพื่อช่วยลดความเสี่ยงจากการเข้าถึงหรือแก้ไขข้อมูลโดยไม่ได้รับอนุญาต
